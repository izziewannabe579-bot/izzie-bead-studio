# Izzie豆作

浏览器本地运行的拼豆图纸编辑器。无需安装依赖，图片在本机处理。

**[在线使用](https://izziewannabe579-bot.github.io/izzie-bead-studio/)** · **[下载离线版](https://github.com/izziewannabe579-bot/izzie-bead-studio/raw/refs/heads/main/Izzie%E8%B1%86%E4%BD%9C-%E7%A6%BB%E7%BA%BF%E7%89%88.html)**

## 功能

- 默认 52×52；支持 4–104 格自定义宽高与 32、40、48、52、78、104 预设。
- 自由 RGB 不限色；可选固定 26 色板或 2–32 色量化，不添加抖动。
- 画笔、橡皮、取色、区域填色、全图换色、50 步撤销/重做。
- 水平/垂直镜像、90°旋转、缩放、拖动、参考图透明度、圆豆预览。
- 施工图 PNG（格内短编号、四周坐标、每 5 格加重线）、原尺寸透明导入图 PNG、完整 HEX/RGB 用量 CSV 和编号表 PNG。
- 项目 JSON 保存与打开，浏览器本地自动保存。

## 使用

上传图片 → 选择配色模式 → 一键转换 → 修整豆位 → 导出施工图、App 导入图和颜色清单。

自定义编号是图纸内部颜色索引，**不是品牌珠子色号**。自动保存和项目 JSON 不包含参考图片，原图请另行保存。颜色较多时，完整编号表按 300 色分页导出；CSV 包含全部颜色。

## 离线使用

下载 `Izzie豆作-离线版.html`，保存到电脑后双击打开即可，无需联网。

## 开发与同步

直接编辑 `index.html` 和 `app.js`。本地预览：

```sh
python3 -m http.server 8000
```

更新离线单文件：

```sh
python3 build_offline.py
```

向 `main` 分支推送后，GitHub Pages 从仓库根目录自动发布。

## 验证

已验证绘图统计与撤销、图片转换、52×52 PNG 豆位和原始 RGB 色，以及施工图编号与用量一致。

## MARD 用色选项

在左侧“用色体系”选择 MARD，现有豆位、图片转换和画笔均吸附到内置 205 色。图纸、编号表和 CSV 使用 MARD 品牌编号；自由 RGB 仍为默认。切换记录在撤销历史与项目 JSON 中。匹配采用 Lab 色差，不添加抖动。RGB 是屏幕参考值，不代表实物测色。

色号数据来自本地 pindou-pattern skill 的 `scripts/colorData.js`（205 色版本）；非官方实时全系列目录。

## 默认减少杂色

图片转换默认合并感知接近的颜色和低对比小色簇，让主要色面更连续；保留高光、深色细节和透明轮廓，不设固定色数。可取消“减少杂色，让色面平稳”保留原色采样，或点击“减少当前图纸杂色”处理已有图纸；操作可撤销。MARD 模式处理后仍匹配品牌色表。

## 52×52 五官结构转译

图片转换采用 nearest 采样，并保存“直接采样 → 减杂色 → 当前修整”的对照；取消减杂色时保留原色。已有图纸也可开始转译，但会如实标为当前图纸起点。

- 记录 3–5 个个体特征，按眼形、视线、虹膜、瞳孔、高光与鼻嘴关系逐格修整；不使用统一五官模板。
- 默认锁住透明轮廓；可手动标记关键豆位，画笔、橡皮、填色、换色和合色均遵守保护。
- 点击三个原尺寸缩略图切换主画布查看；基线只读，导出始终使用当前修整版。可标出修改位置并切换圆豆预览。
- 导出三版对照 PNG、逐格前后 HEX/列/行/部位/原因 CSV；保存项目包含三版、特征和保护标记，支持撤销与重做。
- 支持打开宠物 skill 的 `gridSize/pixelData` JSON；旧项目继续兼容。
- 修整后禁用整图合色，避免覆盖五官；更换尺寸、旋转、镜像或用色体系时重置不兼容的对照，撤销可恢复。

本工具提供人工结构转译工作台，不自动识别动物解剖，也不宣称识别率。高分辨率插画与实际品牌珠子色差仍需对照判断。
