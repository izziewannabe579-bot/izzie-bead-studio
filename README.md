# Izzie豆作 · 拼豆图纸工作室

双击 `Izzie豆作-离线版.html` 即可使用，无需安装依赖或联网。

默认 52×52，自由 RGB 不限色。支持画笔、橡皮、取色、区域填色、全图换色、50 步撤销/重做、镜像、旋转、参考底图、缩放、圆豆预览、图片转换及项目 JSON 保存。

导出：施工图 PNG、原尺寸透明 PNG、自定义编号 HEX/RGB 用量 CSV、完整编号表 PNG。编号不是品牌珠子色号。26 色模式使用界面固定色板，其余 2–32 色通过加权中位切分量化。

图像在浏览器本地处理。自动保存不包含原参考图，原图请另行保存。

## 画作、专辑封面与卡通人物

右侧“图片转拼豆”是统一入口，支持通用图片、画作、专辑封面、卡通人物和宠物头像。不需要先制作宠物插画，也不会把画作或人物裁成宠物头像。

1. 设置整图宽高，上传 PNG、JPG 或 WebP，选择图片类型。
2. 默认“完整构图·等比留空”，保留原图全部内容、背景和留白。仅主动选择“铺满画布·居中裁切”时才裁掉超出部分；不拉伸。
3. 画作、封面与通用图片默认保边采样：有连贯分界时优先保留主色面，柔和渐变保留区域采样；卡通与宠物默认原色采样。可手动切换；图片类型也决定默认合色容差（画作/封面较轻），不规定色数，不添加抖动。
4. 白色仍为有豆区域，去白默认关闭。主动勾选后只移除从画面边缘连通的近白背景；封闭内部白色细节保留，连接到背景的白色主体也可能被移除，请检查。
5. 自由 RGB 下选择“原色采样”“普通转换”并取消“减少杂色”可保留普通采样原色；MARD 和限色模式仍会匹配颜色。最长边超过 2048px 的输入先等比预缩，并在转换状态中如实提示。
6. 转换后可比较采样、减杂色和当前修整版，标记并保护描边、文字、高光等关键豆位；宠物类型继续显示专用五官检查。项目 JSON 保留图片类型、构图/采样设置和三版记录，旧宠物项目仍兼容。

低格数无法保证封面小字、细线和人物表情清晰，优先提高整图格数，再使用 52×52 分板。转换是本地采样、合色和人工修整，不调用 AI 重绘或上传照片。


## 文字与人物服饰的边界保护

“结构处理”默认在宽高均不超过 104 格时启用，覆盖 32、48、52、78、104 格。选择“普通转换”可关闭合色/品牌边界保护；若需完整复现旧的普通采样，同时将采样方式选为区域采样或原色采样。

- 保边采样仅在每颗豆的原图覆盖区域具有连贯色面分界时选择主色面，避免肤色、浅色衣服、背景被平均成同一种过渡色。均匀渐变和交错纹理不强行锐化。
- 在减杂色阶段保护连续分界，边界附近采用更小的感知合色容差，仍合并相近杂色，不设置固定颜色上限。
- MARD 匹配只对有连续证据、被匹配成相同色号的边界，尝试误差预算内的相邻品牌色；不会为浅色衣服凭空勾黑边。所有结果仍严格使用内置 MARD 色表。品牌色卡无法表示的微小色差不能保证保留。
- 高对比、近乎单色的浅字深底横向带单独处理，按原图中心采样保留笔画位置，减少灰色字边。不是 OCR，不补字、不改文字内容或排版，不保证 32 格的小字可读。
- “普通采样 → 保结构＋减杂色 → 当前修整”保留对照。自动保护位置可选择显示、取消保护或清除标记；项目 JSON 保存保护点与处理状态。
- 原图透明轮廓不扩张，不自动镜像。水平镜像是明确的整图操作，文字也会反向，操作后会提示，导出保持当前图纸方向。
- 属于本地像素结构处理，不声称理解人物、衣物、皮肤等语义。复杂遮挡、相近材质仍需对照原图人工修整或增加整体格数。

本实现为独立浏览器算法；PixelOE 仅用于本地对照研究，未将 PyTorch、OpenCV 或外部识别 API 加入网页。参考项目：https://github.com/KohakuBlueleaf/PixelOE 。


## 52×52 拼豆板分割大画幅

画布支持 4–416 格，自定义宽高；增加 156、208 格快捷尺寸。按整图上传、转换和修整后，点击顶部“52×52 分板”，下载分板施工包 ZIP。比如 104×104 为 2×2 共 4 板，156×104 为 3×2 共 6 板；非整倍数不缩放，最右／下方板补空位。

- 包内有拼接总览、各板施工图 PNG、52×52 透明导入图、逐板与整图用量 CSV、可检查重组的分板数据 JSON。
- 统一从左上起排，R 表示板行，C 表示板列；不自动镜像。每板坐标从 1–52 开始，标题另标整图范围；四周坐标、每 5 格加重线和格内编号均保留。
- 先对整图处理颜色，再分板，不逐板重新量化。自由 RGB 编号在全图一致，MARD 使用真实内置品牌编号。白豆带编号，透明空位无编号；灰色区域超出原画幅，不放豆。
- 保留空板的位置。每张图纸附本板色卡与本板用量；超过 45 色时色卡分页，同一板的网格重复，不代表新增拼豆板。
- 解压整个 ZIP 后打开“打印图纸.html”，可打印或在浏览器里另存 PDF。默认 A4，按网格照着施工，**不是实物 1:1 垫板图**。
- 超出整图 PNG 的安全画布容量时，会提示使用分板包。极端色数超过 512 页或施工包大于 256MB 时明确报错，建议先减杂色或选择 MARD，不静默删色。


## MARD 用色选项

在左侧“用色体系”选择 MARD，现有豆位、图片转换和画笔均吸附到内置 205 色。图纸、编号表和 CSV 使用 MARD 品牌编号；自由 RGB 仍为默认。切换记录在撤销历史与项目 JSON 中。匹配采用 Lab 色差，不添加抖动。RGB 是屏幕参考值，不代表实物测色。

色号数据来自本地 pindou-pattern skill 的 `scripts/colorData.js`（205 色版本）；非官方实时全系列目录。

## 默认减少杂色

图片转换默认合并感知接近的颜色和低对比小色簇，让主要色面更连续；保留高光、深色细节和透明轮廓，不设固定色数。可取消“减少杂色，让色面平稳”保留原色采样，或点击“减少当前图纸杂色”处理已有图纸；操作可撤销。MARD 模式处理后仍匹配品牌色表。

## 52×52 五官结构转译

选择“宠物头像”时默认采用 nearest 原色采样，并保存“直接采样 → 减杂色 → 当前修整”的对照；取消减杂色时保留原色。已有图纸也可开始转译，但会如实标为当前图纸起点。

- 记录 3–5 个个体特征，按眼形、视线、虹膜、瞳孔、高光与鼻嘴关系逐格修整；不使用统一五官模板。
- 默认锁住透明轮廓；可手动标记关键豆位，画笔、橡皮、填色、换色和合色均遵守保护。
- 点击三个原尺寸缩略图切换主画布查看；基线只读，导出始终使用当前修整版。可标出修改位置并切换圆豆预览。
- 导出三版对照 PNG、逐格前后 HEX/列/行/部位/原因 CSV；保存项目包含三版、特征和保护标记，支持撤销与重做。
- 支持打开宠物 skill 的 `gridSize/pixelData` JSON；旧项目继续兼容。
- 修整后禁用整图合色，避免覆盖五官；更换尺寸、旋转、镜像或用色体系时重置不兼容的对照，撤销可恢复。

本工具提供人工结构转译工作台，不自动识别动物解剖，也不宣称识别率。高分辨率插画与实际品牌珠子色差仍需对照判断。

## 施工图底部色卡

导出的施工图底部直接附颜色色块、编号、HEX 和豆数，超过 32 色也完整显示。高度按实际色数扩展，白色色块有边框；极端大图按画布容量明确分页，每页仍附施工图与对应色卡。独立 CSV 和编号表继续保留。
